# BLACKBOX Railway Edition v3

## 概要
- Node.js + Express で動く15ステージの架空CTF調査ゲームです。
- 回答の正誤判定はサーバー側で実行します。正解は `server.js` 内のハッシュのみで保持し、HTMLや `game.js` に正解文字列を入れていません。
- ステージ04・08・12の一次認証後は追加調査ページへ移動します。追加認証が通ると、サーバーが次のステージURLを返します。
- 未解除ステージと追加調査ページへの直接アクセスはサーバー側で制限します。
- 全ファイルをリポジトリのルートに置く構成です。

## Railwayへのアップロード
1. ZIPを展開します。
2. **中のファイルをすべて** GitHubリポジトリ `haking2` の一番上（ルート）へアップロードします。フォルダーごと入れ子にしないでください。
3. 既存の同名ファイルは新しいものに置き換え、`server.js`、`package.json`、`railway.json` を必ず含めます。
4. GitHubへコミットします。Railwayがそのリポジトリを監視していれば自動で再デプロイされます。
5. Railwayの公開URLを開き、トップページから「調査を開始する」を押します。
6. `/health` を開くと `{"ok":true,"service":"BLACKBOX",...}` が返ることを確認できます。

## 注意
- RailwayのURLを使ってください。GitHub PagesのURLではサーバーAPIは動きません。
- セッションはこのプロトタイプではメモリ保存です。サーバー再起動・再デプロイで進行状況がリセットされることがあります。
- `SESSION_SECRET` をRailwayのVariablesに設定すると、再起動時のセッション署名キー変更を避けられます。
- `server.js` は正解の平文ではなくSHA-256ハッシュを保持します。ハッシュもサーバー側にだけ置き、ブラウザーには送信しません。
- 回答制限は基本的な対策です。本格的な公開運用にはIP単位のレート制限、永続セッションストア、CSRF対策、ログ監視などを追加してください。
- ゲーム内の資料はすべて架空です。外部サイトを攻撃する必要はありません。
